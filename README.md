# 場所履歴マップ

iPhoneに記録された位置情報を利用して、過去の移動履歴を地図上で確認できるiOSアプリです。

地図から調べたい場所を検索すると、その周辺で位置情報が記録された日を確認できます。
日付を選択すると、その日の移動経路を地図上で表示できます。

過去に訪れた場所や、その日の移動をあとから振り返るために利用できます。

## 主な機能

- iPhoneに記録された位置情報を利用した移動履歴の表示
- 移動履歴を地図上に表示
- 日付を指定して移動履歴を確認
- 地図から場所を検索
- 検索した場所の周辺に移動履歴がある日を表示
- 選択した日の移動経路を表示
- 移動履歴の保存期間を設定
- 移動履歴の記録設定

## 位置情報について

本アプリは、移動履歴を記録し、地図上で確認するために位置情報を利用します。

移動履歴を記録するには、設定で「移動履歴を記録」を有効にする必要があります。

## プライバシー

移動履歴などのデータは、アプリの機能を提供するために利用者の端末上で管理されます。

本アプリでは、移動履歴などのデータを外部サーバーへ送信しません。

詳しくは、[プライバシーポリシー](privacy.html)をご覧ください。
